## 🎯 Sobre

**CYBER** é um portfólio de cibersegurança interativo e de alto nível, desenvolvido para pesquisadores de segurança, pentesters, profissionais de Red Team e hackers éticos que desejam apresentar seus trabalhos com estilo e sofisticação.

Construído com uma **estética inspirada em terminais**, o portfólio apresenta:

* 🌐 **Fundos 3D interativos** desenvolvidos com Three.js
* 💚 **Efeitos de chuva no estilo Matrix** para uma autêntica atmosfera hacker
* ⚡ **Animações de texto com efeito glitch** e divisão RGB
* 🖥️ **Interfaces de terminal simuladas** com execução de comandos em tempo real
* 🌍 **Suporte multilíngue (i18n)** através de `pt.json` e `en.json`, com seletor global de idioma
* 🎨 **Cursor personalizado** com diferentes estados ao passar sobre elementos
* 📱 **Design totalmente responsivo** para todos os dispositivos

> *"Quebrando sistemas. Construindo confiança."* — **Alex Vance**

## 🎨 Recursos

### ✨ Efeitos Visuais

* **Rede de Partículas 3D** — Gráfico de nós animados com efeito de paralaxe controlado pelo mouse
* **Icosaedro em Wireframe** — Formas geométricas rotativas
* **Chuva Matrix** — Clássico efeito de caracteres caindo no fundo
* **Overlay de Scanlines** — Simulação de monitor CRT
* **Tipografia Glitch** — Animações de texto com divisão RGB
* **Grade Hexagonal** — Efeitos interativos ao passar o mouse

### 🧩 Componentes Interativos

* **Seletor Global de Idioma** — Alternância estilizada com `🌐` entre `PT` e `EN`
* **Emulador de Terminal** — Interface de linha de comando simulada
* **Barras de Habilidades Animadas** — Indicadores de progresso ativados durante a rolagem
* **Estatísticas Animadas** — Números animados quando entram na área visível
* **Transições ao Passar o Mouse** — Microinterações suaves
* **Cursor Personalizado** — Cursor com anel verde e modo de mesclagem
* **Animações de Revelação** — Elementos que aparecem gradualmente utilizando Intersection Observer

### 📄 Seções de Conteúdo

| Seção              | Descrição                                          |
| ------------------ | -------------------------------------------------- |
| 🏠 **Hero**        | Título com efeito glitch e botões de ação          |
| 👤 **Sobre**       | Perfil em estilo terminal + estatísticas           |
| 💪 **Habilidades** | Barras de progresso animadas                       |
| 🛡️ **Serviços**   | 6 cards de serviços com ícones                     |
| 📁 **Projetos**    | 6 cards de estudos de caso com trechos de código   |
| 📧 **Contato**     | Formulário criptografado com informações sobre PGP |

### 🎛️ Recursos Técnicos

* ✅ Zero dependências, exceto bibliotecas via CDN
* ✅ Suporte multilíngue (`pt.json` e `en.json`)
* ✅ Deploy em arquivo único
* ✅ HTML semântico otimizado para SEO
* ✅ Acessível e preparado para ARIA
* ✅ Animações otimizadas para desempenho
* ✅ Breakpoints responsivos para dispositivos móveis

## 🛠️ Tecnologias

### Core

* **HTML5** — Marcação semântica
* **CSS3** — Custom Properties, Grid, Flexbox e animações
* **JavaScript Vanilla** — Módulos ES6+

### Bibliotecas via CDN

| Biblioteca                                                           | Versão       | Finalidade         |
| -------------------------------------------------------------------- | ------------ | ------------------ |
| [Three.js](https://threejs.org/)                                     | r128         | Renderização 3D    |
| [Orbitron](https://fonts.google.com/specimen/Orbitron)               | Mais recente | Fonte para títulos |
| [Share Tech Mono](https://fonts.google.com/specimen/Share+Tech+Mono) | Mais recente | Fonte do terminal  |
| [Rajdhani](https://fonts.google.com/specimen/Rajdhani)               | Mais recente | Fonte principal    |

### Ferramentas Utilizadas

* 🎨 Animações CSS personalizadas
* 📐 Intersection Observer API
* 🖱️ Eventos de rastreamento do mouse
* 📊 Canvas 2D API para o efeito Matrix
* 🌐 WebGL através do Three.js
